# Anton Zorin — Frontend Engineer Portfolio

Одностраничный адаптивный лендинг-портфолио, реализованный по дизайну **SIGNAL / STRUCTURE**. Страница представляет профессиональный опыт, публичные проекты и инженерный подход.

Проект собран на Nuxt 4, Vue 3, TypeScript и SCSS и генерируется как статический сайт.

```bash
pnpm install
pnpm dev
```

Production-сборка:

```bash
pnpm generate
```
